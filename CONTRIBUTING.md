# Contributing to ZorOS
the operating system is free for work and study, ok, but if you want to use, you can make distribution of it, but you need to credit me and the team, ok?

### how to contribute
- fork the repository
- create a branch
- make changes
- submit a pull request

## How to make a branch
``` bash
# create a branch
git branch <branch_name>

# switch to the branch
git checkout <branch_name>

# push the branch
git push -u origin <branch_name>
```
